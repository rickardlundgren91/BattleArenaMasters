# BAM Highlight Studio

Read the active rebuild's `Assets/BAM/` replay/recording and match event implementation **if present** and the latest `Docs/ARCHITECTURE.md`. The older XYZ `MatchRecorder` and `MatchExport` are *not proof* that the new BAM rebuild can export videos. Identify existing capture tools first.

## Reel workflow
- Select real gameplay: 3v3 team combos, clutch tower takedowns, true skill hits, escape, fails and rare interactions. Never invent match footage or depict an unimplemented hero/skill as shipped.
- For each candidate require real source file/match ID, timestamp, confirmed event and gameplay-context explanation. If none exists, draft a capture plan rather than pretending videos were produced.
- Offer vertical 9:16 shot plan: instant hook, build-up, action payoff, concise overlay and correct BAM logo, all readable on a phone. Separate genuine bot footage from real PvP or staged concept clips.
- Validate licensed audio, footage, music rights and graphics; check actual HUD cropping and no misleading performance claims.
- Never post or publish without Simon's and Rickard's approval.

Deliver ranked timestamped clips when available, otherwise an honest production checklist and a detailed capture request for the local Unity build.
