# Online protocol history

`MpWire.Protocol` (`Assets/BAM/Online/Mp/MpWire.cs`). Phones with different protocols never meet online, and a match trace
can only be replayed with the rules of the protocol it was recorded with. Bump it whenever a message or the rules' input
changes, and add one line here: `python3 protocol.py bump --project . "what changed"` (bam-work/review/full-2026-11-13/rest/paket-4/),
or by hand at the end of the list. Protocol 1 was the first online build.
